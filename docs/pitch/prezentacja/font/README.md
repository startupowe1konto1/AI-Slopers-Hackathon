# Archivo

Font zmienny Archivo (szerokość 62–125%, grubość 100–900) w dwóch podzbiorach z Google Fonts (v25): `archivo-latin.woff2` i `archivo-latin-ext.woff2` (polskie znaki). `build_standalone.py` wpisuje oba pliki do samodzielnego HTML, żeby prezentacja wyglądała tak samo bez sieci.
